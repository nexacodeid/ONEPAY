Tambah Stok Massal

Aturan Format Massal:

  • Gunakan Enter untuk menambah baris antar kolom.
  • Gunakan Titik Dua ( : ) untuk memisahkan Nama Kolom dan Isinya.
  • Gunakan Koma ( , ) untuk memisahkan antar Stok.

Panduan Lengkap Penggunaan

1. Produk Statis vs Dinamis

  • Statis: Cocok untuk produk yang tidak butuh data stok spesifik (misal: Joki, Topup via ID). Kamu bebas membuat nama kolom yang nantinya wajib diisi oleh pembeli saat transaksi.
  • Dinamis: Cocok untuk produk akun/software siap kirim. Sistem akan mengunci pembelian sesuai dengan ketersediaan stok fisik yang kamu masukkan di sini.

2. Sistem Kolom Data (Field)

Web ini tidak membatasi bentuk data. Kamu bebas menambah tombol "+ Kolom" di setiap varian atau stok. Ganti Key (contoh: "Email") dan Value (contoh: "admin@mail.com") menyesuaikan jenis produk jualanmu.

3. Tambah Stok Massal (Khusus Dinamis)

Gunakan format ini di menu aksi "Massal" untuk memasukkan ratusan akun sekaligus tanpa ketik satu per satu:

Email: akun1@mail.com
Pass: 123456,
Email: akun2@mail.com
Pass: qwerty
  • Titik Dua ( : ) untuk memisahkan Nama Kolom dan Isi kolomnya.
  • Enter (Baris Baru) untuk menambah baris informasi dalam 1 stok yang sama.
  • Koma ( , ) untuk mengakhiri 1 stok dan memotong data agar beralih ke stok berikutnya.

4. Aksi Cepat (Duplikat & Hapus Massal)

Centang kotak kecil di sebelah kiri varian/stok. Tombol "Hapus Terpilih" warna merah akan muncul di atas untuk membersihkan data dalam sekejap. Gunakan tombol "Duplikat" untuk menyalin stok yang sama berkali-kali tanpa ribet ketik ulang.
